# Stellenbosch Technologies Homebrew tap

Homebrew formulae for [rhebok](https://github.com/Stellenbosch-Technologies/rhebok),
local retrieval and memory for AI coding agents.

## Install rhebok

```bash
brew install stellenbosch-technologies/tap/rhebok
rhebok install
```

`rhebok install` finishes the setup: it registers the Claude Code plugin,
offers to connect your other agents and downloads the embedding model. rhebok
needs [Ollama](https://ollama.com) running.

The formula supports a Mac with Apple silicon, and Linux on x86_64 or arm64
with glibc 2.39 or newer.

## Update

```bash
rhebok update
```

This runs `brew upgrade rhebok`, then `rhebok install`, so the Claude Code
plugin matches the new version.

## How the formula is made

`Formula/rhebok.rb` is generated by `scripts/homebrew-formula.sh` in the rhebok
repository, which reads each build's checksum from the published release. See
[docs/releasing.md](https://github.com/Stellenbosch-Technologies/rhebok/blob/main/docs/releasing.md#homebrew).
Report problems in the [rhebok issues](https://github.com/Stellenbosch-Technologies/rhebok/issues).
